# GitHub Upload Checklist

- [ ] Add your original `mp3_to_json.py` to `src/`
- [ ] Add your existing `embeddings.joblib` if you want to publish the generated artifact
- [ ] Keep large videos/MP3 files out of normal Git history
- [ ] Check that no API keys, passwords or private files are present
- [ ] Add a repository description
- [ ] Pin the repository on your GitHub profile
- [ ] Add screenshots to the README if desired
